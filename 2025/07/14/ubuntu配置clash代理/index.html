1. 下载 Clash

你可以访问 Clash release page 来找到最新的版本。

对于局域网内其他设备

如果你的 Clash 配置中 allow-lan 设置为 true，并且你的防火墙允许外部连接到 Clash 的端口 (例如 7890 或 7891)，那么你可以在其他设备的网络设置中，将代理服务器地址设置为你的 Ubuntu 服务器的 IP 地址，端口设置为 Clash 监听的端口。

6. Web UI (可选)

Clash 提供了一个 Web UI 来方便管理和查看配置。你需要确保你的 config.yaml 中配置了 external-controller。

然后，你可以从 Clash 的 GitHub 页面下载 Web UI 静态文件，或者使用已有的 Web UI 项目（如 Yacd）。将 Web UI 文件放在 Clash 可执行文件旁边的 ui 目录下，或者通过 external-ui 参数指定路径。

如果你想从外部访问 Web UI，你需要将 external-controller 设置为 0.0.0.0:9090，并在防火墙中允许该端口。

配置 Clash 需要对代理协议和网络有一定的了解。如果你遇到问题，检查 Clash 的日志 (sudo journalctl -u clash -f) 通常能提供有用的信息。
